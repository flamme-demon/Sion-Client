# Polices embarquées

Outfit est utilisé pour les titres, Roboto pour le corps du texte.
Les WOFF2 variables couvrent les graisses 100 à 900 et les sous-ensembles
latin et latin étendu. Roboto est fourni en romain et en italique.
Les autres écritures utilisent les polices de remplacement du système.

Fichiers officiels téléchargés sans modification le 8 octobre 2026 depuis
l'API CSS de Google Fonts : Outfit v15 et Roboto v51.

Sources et licences SIL Open Font License 1.1 :

- [Outfit](https://github.com/google/fonts/tree/main/ofl/outfit), `Outfit-OFL.txt`.
- [Roboto](https://github.com/google/fonts/tree/main/ofl/roboto), `Roboto-OFL.txt`.
